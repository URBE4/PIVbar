## 📥 Как сохранить спрайт

### Вариант 1: Вручную через VS Code

1. Откройте прикреплённое изображение `pulse-tower-spritesheet.png`
2. Перетащите его в папку: `/workspaces/codespaces-blank/bar-td-web/assets/towers/`
3. Переименуйте в: `pulse-spritesheet.png`
4. Запустите `npm run dev`

### Вариант 2: Через терминал

```bash
# Если у вас есть файл локально:
cp ~/Downloads/pulse-tower-spritesheet.png /workspaces/codespaces-blank/bar-td-web/assets/towers/pulse-spritesheet.png
```

### Вариант 3: Из браузера

1. Откройте адрес: `file:///workspaces/codespaces-blank/bar-td-web/index.html`
2. Откройте консоль браузера (F12)
3. Можно сразу тестировать иконки башен через Canvas

## 🔧 Если спрайт не загру этот

Проверьте консоль браузера (F12 → Console):

```javascript
// Должны быть логи:
// ✅ Loaded sprite sheet for tower type: pulse
// ✓ 12 modules transformed
```

Если вместо этого видна ошибка:
```javascript
// ⚠️ Failed to load sprite sheet for pulse: 404
```

Значит файл не в правильной директории. Правильный путь:
```
/workspaces/codespaces-blank/bar-td-web/assets/towers/pulse-spritesheet.png
```

---

## 🎨 Отладка визуала

Если спрайт загружен, но выглядит неправильно:

1. Проверьте `columnsPerRow: 8` в `assets/towers.json`
2. Убедитесь, что каждый фрейм ровно 40x40 пиксели
3. Проверьте, что спрайт-шит в формате PNG с прозрачностью
