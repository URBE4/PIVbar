# BAR Tower Defense

Структура проекта создана по вашему шаблону.

## Запуск

Откройте `index.html` в браузере через локальный сервер (например, `python3 -m http.server 8000`).

## Структура

- index.html
- css/style.css
- js/core/Game.js
- js/core/ResourceManager.js
- js/core/SaveSystem.js
- js/gameplay/
- js/ui/
- js/data/
- assets/
